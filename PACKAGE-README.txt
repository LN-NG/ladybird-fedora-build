Ladybird for Fedora 44 x86_64

Extract into a directory and run ./bin/Ladybird from that directory.
This package contains Ladybird, its resources, helpers and vcpkg libraries.
Qt, glibc, GPU drivers and other Fedora system libraries are not bundled.

Runtime packages:
sudo dnf install qt6-qtbase-gui qt6-qtpositioning qt6-qtwayland liberation-sans-fonts pulseaudio-libs

This is an unofficial build of pre-alpha software, not an upstream release.
The upstream commit is recorded in SOURCE-REVISION.
